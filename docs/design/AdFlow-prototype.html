05 Client add / edit Side panel, 460px, over a 0.28 scrim · sticky header and footer · body scrolls
Why a side panel, not a modal. The form is 12–16 fields with a branch: a centred modal that tall either scrolls inside a floating box or fills the viewport, and both feel wrong for a data entry task you repeat. A right-edge panel keeps the client list visible behind it (you're often copying an ID from a sibling location), gives a fixed 460px measure so labels and inputs never reflow, and lets the header/footer pin while only the body scrolls. Modals stay reserved for destructive confirmation.
